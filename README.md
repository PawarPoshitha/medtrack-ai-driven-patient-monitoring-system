# MedTrack – AI-Driven Patient Monitoring System

## Overview

MedTrack is an AI-based patient monitoring system developed using Spring Boot, MySQL, and Random Forest. The system supports patient monitoring and health-risk prediction through role-based dashboards.

## Technologies Used

* Java
* Spring Boot
* MySQL
* Random Forest
* REST APIs

## Key Features

* AI-based health risk prediction
* Patient monitoring
* Role-based dashboards
* Patient data management
